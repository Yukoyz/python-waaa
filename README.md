# 🎓 El "Más Mejor" Diploma Generator
*Un proyecto inspirado en "Un Show Más" para demostrar lógica básica en Python.*

## 📝 Descripción
Este programa simula el sitio web donde Rigby intenta obtener su diploma de preparatoria. Es un examen de consola que evalúa respuestas, maneja errores de entrada y utiliza lógica condicional para determinar si el usuario es "apto" para graduarse.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** Python 3.x
* **Conceptos aplicados:** * Entrada de datos (`input`)
    * Estructuras condicionales (`if`, `elif`, `else`)
    * Manipulación de strings (`.lower()`, `.strip()`)

## 🚀 Cómo ejecutarlo
1. Clona este repositorio o descarga el archivo `main.py`.
2. Asegúrate de tener Python instalado.
3. Ejecuta el comando:
   ```bash
   python main.py
